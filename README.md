# AeroCore
Offline 6DoF flight simulator &amp; avionics suite built with C, C++17/C++20, Assembly (SIMD/RVV), and Qt 6. Managed via CMake &amp; Git. Features zero-alloc ring buffers, SITL telemetry emulation, SQLite logging, climate control, and UDP multicast multimedia streaming. Designed following MISRA C++ for bare-metal RTOS &amp; RISC-V architectures.
